# Project working priorities

- The owner's priority is **frontend deployment**. Ship a working, reviewable
  frontend and verify its public URL before expanding backend or later-roadmap work.
- Finish backend dependencies required by the current frontend flows, including
  authentication, data privacy and moderation; keep additional backend work scoped.
- Keep the main app hub (`apps/web`), Reviews (`apps/reviews`) and the independent
  Discover fork separate. Each frontend must use its own hosting project identity.
- Record what was actually deployed and checked. Do not describe a local build,
  queued deployment, or untested email/browser flow as a verified public result.

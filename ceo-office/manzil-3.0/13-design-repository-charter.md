# 🗃️ MANZIL DESIGN REPOSITORY — Charter (v1.0)

> Captured 2026-08-05. **The planning phase is formally closed** — this is the last
> specification. The Design Repository is the "source code" of the UI before any
> mobile code: from the next session, every deliverable is directly usable by a
> designer or developer.

## Contents

1. **Every component** (AI Input Bar, Business/Story/Package/Review Cards, Booking Timeline, Profile Header, Floating Widgets, Smart Chips, Bottom Sheets…) — variants, states, animations, accessibility, tokens, developer props.
2. **Every screen** — wireframe, layout grid, components used, motion, API requirements, empty/loading/error states.
3. **Every flow** — complete interaction maps (video → tap business → profile → ask AI → package → booking → payment → review → story).
4. **Every animation** — splash, AI thinking, story progress, hero transitions, pull-to-refresh, card expansion, booking confirmation, payment success, AI typing, voice waveform — each with duration, easing, trigger, reduced-motion alternative.
5. **Design tokens** — colors, spacing, typography, radius, shadows, motion, icons. No hard-coded values.

## MVP Sprint Plan (16 weeks)

1. Foundation — project setup, auth, onboarding, design system, theme, navigation, API client
2. AI — chat, voice, memory, suggestions, context handling
3. Discovery — For You feed, stories, videos, search, nearby
4. Business — profiles, reviews, media, services
5. Booking — calendar, availability, payments, confirmation, notifications
6. Social — user profiles, stories, reviews, collections
7. Merchant — dashboard, bookings, analytics, promotions
8. Polish — performance, accessibility, QA, beta release

## ⭐ ADOPTED ADDITION (user, 2026-08-05): The Experience Platform

Reviews are not the end of the journey. A completed experience automatically becomes a **timeline** (Birthday: venue ✔ cake ✔ taxi ✔ photos ✔ friends ✔ story ✔ review ✔ memory ✔) that users revisit, share, or duplicate next year. Manzil becomes a personal experiences platform, not a booking app. *(Pairs with the Smart Plan Workspace — the plan lives before, during, and after the event.)*

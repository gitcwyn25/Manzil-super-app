## Stages

1. ✅ **Product Foundation** — Bible, IA, AI Bible, Tech Architecture, Design System, Component Library, Screen Bible. We know WHAT we're building.
2. **Product UX (NEXT)** — the **UX Blueprint**: one giant interactive map of the app. Every tap, swipe, animation, and AI interaction documented. The foundation of everything.
3. **Wireframes** — ~250, no colors/shadows/gradients, pure UX, fast iteration.
4. **High Fidelity** — only after UX is final: colors, motion, glass, icons, typography, shadows, components.
5. **Interactive Prototype** — AI/booking/story animations, hero transitions, voice, gestures; near-identical to the finished app.
6. **React Native build** — straightforward because every screen already exists.

## Build the WOW Flow first

Investors and users judge an app in the first minute; the first 10 minutes must be unforgettable:

```
Splash → Onboarding → Permissions → Interests → AI Setup → Home
→ For You → Business → AI Planning → Booking → Success
```

If this flow is exceptional, everything else is easier to expand.

## REFINEMENT ADOPTED (user, 2026-08-05): Three modes, final form

Manzil should feel **simpler** than "TikTok + Pinterest + Instagram + AI" — the best products hide complexity. Everything in the app lives inside three modes:

1. **Discover** — watch, explore, get inspired. Content-first. *(absorbs Nearby)*
2. **Plan** — talk to Gurman AI, organize experiences, compare options, book everything.
3. **Experience** — bookings, stories, reviews, rewards, memory.

*(Supersedes the earlier Discover / Explore Nearby / Plan-with-AI naming in 02-information-architecture.md — Discover·Plan·Experience is the canonical trio.)*

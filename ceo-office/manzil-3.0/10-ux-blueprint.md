# 📍 MANZIL UX BLUEPRINT — v1.0

> Captured 2026-08-05. The single most important product document: "What happens
> from the moment a user opens the app until they accomplish a real-world goal?"
> We are NOT designing an app — we are designing a **product ecosystem**: every
> screen, animation, API, and AI capability exists because it serves a complete
> user journey.

## Product DNA — three pillars

```
DISCOVER → PLAN WITH AI → EXPERIENCE
```

Everything in the app belongs to one of these three pillars.

## User Lifecycle (retention strategy)

Never heard of Manzil → downloads → creates account → personalizes → discovers businesses → first booking → first story → uses AI regularly → invites friends → loyal user → power user → **ambassador**.

## Primary Journeys

1. **First Launch:** Splash → Welcome → Sign Up → Permissions → Interests → Meet Gurman AI → Home. Goal: "Wow."
2. **Discovery:** Home → For You → business video → business profile → save → share → ask AI → book.
3. **AI Planning:** Open AI → birthday → budget → guests → compare packages → edit → confirm → book everything.
4. **Barber:** voice → "need haircut" → nearby → compare → choose → book → navigate → review. **Goal: under 90 seconds.**
5. **Restaurant:** search → restaurant → menu → availability → reserve → navigate → review → story.
6. **Tourist:** airport → nearby → hotel → taxi → restaurants → AI guide → itinerary.

## AI Decision Framework

Understand → retrieve context → ask only if needed → search → rank → compare → recommend → explain → book → follow up.

## Universal Screen Pattern

Status bar → context header → main content → contextual actions → **persistent AI bar** (the signature of Manzil).

## Navigation Philosophy

Context-adaptive, not fixed tabs: exploring → discovery quick actions; planning → planning tools prominent; booking → booking actions take priority.

## The Three Core Experiences

- **Discover** — purpose: inspiration; content: videos, stories, collections, recommendations; primary action: save or ask AI.
- **Plan** — purpose: turn an idea into a concrete plan; content: AI conversation, comparisons, budgets, itineraries; primary action: book.
- **Experience** — purpose: enjoy, remember, share; content: bookings, navigation, reviews, stories, achievements; primary action: reflect and inspire others.

## Success Metrics (outcomes, not scrolling)

Time to first successful booking · AI task completion rate · repeat bookings · user satisfaction · business satisfaction · repeat usage after completed experience · invitations sent · reviews and stories created after visits.

## ADOPTED PRINCIPLE (user, 2026-08-05): "Every Screen Must Lead Somewhere"

No dead ends. A restaurant page → booking, saving, sharing, or asking AI. A story → the business profile. A review → similar places. A completed booking → reminders, navigation, review. Every screen encourages meaningful progress, never passive browsing.

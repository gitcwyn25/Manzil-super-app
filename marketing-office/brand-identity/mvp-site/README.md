# Manzil MVP Website

This is the first customer-facing MVP for Manzil, a Tashkent-first local business discovery and reviews platform.

## What is included

- Search-first homepage
- Category filtering
- Business result cards
- Business profile preview
- Review submission demo with validation
- Business claim request demo
- Responsive desktop and mobile layouts
- Manzil design tokens from the existing Stitch design system

## How to open

Open `index.html` directly in a browser.

## Current limitations

- Data is static demo data.
- Forms validate locally but do not persist.
- Map view is represented visually only.
- Fonts fall back to local system fonts if Geist and Inter are not installed.

## Recommended next step

Move this UI into the documented production stack:

- Next.js
- TypeScript
- Tailwind CSS
- Server-rendered business profile pages
- API-backed search, reviews, and claim flows
